# Black Jack

Ett enkelt Black Jack-spel byggt med HTML, CSS och JavaScript.

## Funktioner

- Registrera och logga in med användarnamn och lösenord
- Pott sparas automatiskt i localStorage mellan besök
- Satsa valfritt belopp innan varje omgång
- Fyll på kassan när pengarna tar slut
- Datorn spelar automatiskt enligt vanliga Blackjack regler (stannar på 17)
- Ess räknas som 11 eller 1 beroende på situationen

## Hur man spelar

1. Registrera ett konto eller logga in
2. Skriv in hur mycket du vill satsa
3. Tryck **Start** för att dela ut korten
4. Tryck **Hit** för att ta ett kort till
5. Tryck **Stand** för att stanna, datorn spelar då sin tur
